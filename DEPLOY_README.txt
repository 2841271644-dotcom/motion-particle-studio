MOTION PARTICLE STUDIO V7 — 公开独立版

一、部署
1. 解压，将 index.html 上传到你网站的目录，设置默认首页为 index.html。
2. 可以部署到国内静态空间、Nginx、宝塔站点、对象存储静态托管或其他普通网页服务器。
3. 没有后端、数据库、npm 安装步骤、GPT 登录、API Key 或 Spine 软件依赖。
4. 字体、脚本、样式和编码逻辑都在本地文件中，无国外 CDN 请求。
5. 正式部署时使用普通静态 HTML 服务即可。index.html 支持放在根目录或子目录。
本包是可供你自行部署的文件；没有替你部署到你的国内域名或服务器。

二、推荐操作
先选择左侧预设或添加系统 → 右侧调整发射模式、粒子与物理 → 时间轴播放预览 → 导出动画。
滑块、数字输入和数字框的箭头均可使用。双击系统名称可以重命名。
内置锚点是可选的进阶功能，不需要安装或学习 Spine。

三、透明导出
- 透明 PNG 序列 ZIP：逐帧 RGBA PNG + manifest.json。适合后期合成和游戏开发，推荐。
- APNG 透明动画：一个 .apng 文件，保留完整半透明。可直接拖入支持 APNG 的浏览器播放。
- 透明精灵图 ZIP：spritesheet.png + spritesheet.json，JSON 给出每帧坐标与帧率。
- 导出当前帧：透明 PNG 静帧，使用当前画面与 960×600 的逻辑画布。
- WebM 预览视频：有底色预览，不作为透明素材交付；编码时长受浏览器录制影响。
PNG 序列和 APNG 由逐帧烘焙生成；帧数为 round(时长×FPS)。
例：30 FPS、0.5 秒得到 15 帧；每帧 1/30 秒。
“动画循环”控制 APNG 是否循环播放，并记录在 PNG 序列元数据中。
辅助网格、发射器线框、锚点、背景图与前景图不会混入透明动画。
输出比例与工作画布不同时，保持比例并居中留透明区域，不拉伸。
APNG 在不支持动画 PNG 的图片软件里可能只显示第一帧；后期工作可改用 PNG 序列。

四、持续发射与循环
持续发射在系统的起播帧开始，并在发射持续时间内按速率产生粒子。
勾选时间轴“循环”后，整个动画周期重复，保留跨周期仍存活的粒子。
瞬时爆发每周期触发一次；常驻固定模式不会逐周期堆积粒子。
发射持续时间与时间轴长度是不同参数。点击“匹配时长”按所有系统排期调整时间轴。

五、保存与导入
“保存工程”保存完整 JSON，包括贴图、系统、曲线与锚点关键帧。
“配置管理”支持当前系统配置、所有系统 JSON、分系统 ZIP，以及 JSON/ZIP 批量导入。
“序列编排”可以调起播帧、时长和层级；取消不改动当前场景。
工程文件请自行保存。浏览器草稿和预设仅保存在当前浏览器，清理浏览器数据会移除它们。
贴图较大时，不要仅依赖自动草稿，应下载工程 JSON 备份。

六、性能与兼容
本次实测环境为桌面 Chrome。没有逐一测试所有国产浏览器内核与移动设备。
编码由本机浏览器完成，分辨率、时长、粒子数量越大，速度越受本机配置影响。
单系统同时存活粒子上限 900，总存活粒子上限 3600；单系统发射速率最高 1000/秒。
一次导出最多 1800 帧，单个 PNG/APNG 烘焙数据累计最多 256MB。
精灵图单边不超过 16384，像素总数不超过 4800 万；过大时会提示改用序列帧。
导出过程中可以点击“取消导出”，取消后不会下载半成品。
